такс, git status показывает файлы, красным горит тот в котором что то менялось но он не выбран 
далее нужно выбрать файл который нам нужен через add
после add пишем название файла без кавычек
затем коммитим, через git commit, после этого в строчке через -m и кавычки задаем имя коммиту, git commit -m "Добавил правки"
затем можно написать git status, чтобы проверить есть ли измененные файлы
